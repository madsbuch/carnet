      Carnet

      Point Carnet at the folder that holds your markdown notes — typically your Dropbox folder. Files stay where they are; Dropbox keeps doing the syncing.

      1. Allow file access

        Your notes live in a folder on this phone, so Android has to grant Carnet “All files access”. Flip the switch in settings, then come back here.

      2. Sync Dropbox to this phone

        The Dropbox app keeps files in the cloud only. Use a sync app — Dropsync, FolderSync, or similar — to two-way sync your Dropbox to local storage, e.g. /storage/emulated/0/Dropbox. Carnet finds the folder once it holds your notes, whichever app put it there.

      3. Open the folder
      or
      Real-time sync (connect Dropbox)

      Skip the folder-sync app: let Carnet talk to Dropbox directly so changes appear within seconds. Create a Dropbox app at dropbox.com/developers — a Scoped app with App folder access and the files.metadata.read, files.content.read and files.content.write scopes — then paste its app key. Your notes live in the app's own folder (/Apps/<your app>), so Carnet can never touch the rest of your Dropbox. Pick Full Dropbox instead only if you need to sync an existing folder in place.
